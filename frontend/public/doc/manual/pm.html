ต้องการแนวทางตั้งชื่อ Work Order / Category / Task / Subtask จากมุมมองไซต์งาน (ใช้คุยตกลงร่วมกับทีมพัฒนา) ดูได้ที่แท็บ Implement Site บนแถบเมนูด้านบน
🗂️ 1 · Workspace (กระดานงาน) มอบหมาย/ติดตามงาน 4 ระดับ ▾

หน้า /workspace — ใจกลางของการมอบหมายและติดตามงาน จัดเป็นลำดับชั้น: หมวดหมู่งานหลัก (Work Order) → หมวดหมู่ย่อย (Category) → งานหลัก (Task) → งานย่อย (Subtask)

"หมวดหมู่งานหลัก" และ "Work Order" คือชื่อเรียกสิ่งเดียวกัน — ระบบไม่มี "ใบสั่งงาน" แยกเป็นอีกสิ่งต่างหาก

1.1 เปิด Workspace และสลับมุมมอง

  1. คลิกเมนู "Workspace"
  2. กดปุ่ม "ตัวกรอง" เพื่อเปิดกล่องตัวเลือก — ในนั้นมีตัวเลือกช่วงเวลา: ทั้งหมด / วันนี้ / สัปดาห์นี้ / เดือนนี้
  3. ตัวกรอง Work Order/Category และปุ่มล้างตัวกรอง อยู่ในกล่องเดียวกันนี้

1.2 สร้างหมวดหมู่งาน

สร้างจากปุ่มที่อยู่ ในฟอร์มสร้างงาน (ไม่ใช่ปุ่มแยกบนแถบเครื่องมือ) — Work Order และ Category เป็น ฟอร์มแยกกัน 2 ฟอร์ม:

  1. เปิดฟอร์มสร้างงาน (1.3) แล้วกดปุ่ม "สร้างหมวดหมู่หลัก" (สร้าง Work Order) → กรอก "รหัสหมวดหมู่งานหลัก (Code) *", "ชื่อหมวดหมู่งานหลัก *", เลือก "หัวหน้ากลุ่มงาน (Leader)" (ไม่บังคับ) → กด "บันทึกข้อมูล"
  2. ต้องการหมวดย่อย: กดปุ่ม "สร้างหมวดหมู่ย่อย" (คนละฟอร์ม, ต้องเลือก Work Order ไว้ก่อน) → กรอก "ชื่อหมวดหมู่ย่อย *" → กด "บันทึกข้อมูล"
ปุ่ม "สร้างหมวดหมู่หลัก" จะไม่แสดงให้ LD และ AM — ปุ่ม "สร้างหมวดหมู่ย่อย" ใช้ได้ทุก role ที่เข้าฟอร์มสร้างงานได้

1.3 สร้างงาน (Task) และงานย่อย (Subtask)

  1. ในหมวดที่ต้องการ กดปุ่ม "เพิ่มงาน" (Quick Create)
  2. กรอก "ชื่องานหลัก *", เลือก "ผู้รับผิดชอบ *" และ "วันที่ครบกำหนด *"
  3. กด "บันทึก" → งานปรากฏบนกระดาน
  4. เพิ่มงานย่อย: เปิดงานหลัก → กด "เพิ่มงานย่อย" → กรอก "ชื่องานย่อย *", "ผู้รับผิดชอบ", "วันที่ครบกำหนด" → บันทึก

1.4 แก้ไข / ลบ Work Order

  1. ที่ตัวเลือก Work Order (ในฟอร์มสร้างงาน หรือรายการหมวดหมู่) กดไอคอน แก้ไข (ดินสอ)
  2. แก้ "ชื่อหมวดหมู่งานหลัก" หรือ "หัวหน้ากลุ่มงาน (Leader)" (ไม่บังคับ) — "รหัส (Code)" แก้ไม่ได้หลังสร้างแล้ว
  3. กด "บันทึกข้อมูล" เพื่อแก้ไข หรือกดไอคอน ลบ แล้วยืนยันเพื่อลบ Work Order (ลบไม่ได้ถ้ามีงานที่เริ่มทำไปแล้วอยู่ในหมวดนี้)
LD และ AM แก้/ลบ Work Order ไม่ได้ — ปุ่มจะไม่แสดงให้ทั้งสอง role นี้ (แต่ทั้งคู่ยังสร้าง/แก้ไขงานและงานย่อยใน Workspace ได้ตามปกติ) · AM ไม่ใช่ read-only — แก้ไขงานได้เท่า LD ยกเว้นจุดนี้เท่านั้น

1.5 ดูประวัติงาน (History)

  1. ที่งานย่อย เปิดเมนู (จุดสามจุด) แล้วเลือก "History"
  2. สลับดูได้ระหว่าง "ประวัติรายงานความคืบหน้า" และ "ประวัติการแก้ไขตั้งค่า"
History มีเฉพาะระดับ งานย่อย เท่านั้น — Work Order ไม่มีหน้าประวัติ
👀 2 · Activity Monitor (ผู้ใช้ออนไลน์ / Login-Logout) ใครออนไลน์ + ประวัติ login/logout ▾

หน้า /activity-monitor — ดูว่าใครออนไลน์อยู่ตอนนี้ และประวัติ login/logout ของผู้ใช้ในระบบ ไม่ใช่การบันทึกว่าใครสร้าง/แก้ไขงานหรือ Work Order (เอกสารรุ่นก่อนหน้าเข้าใจผิดเรื่องนี้)

วิธีใช้แบบละเอียดอยู่ที่ GOD › Activity Monitor (Single Source of Truth) — และหน้านี้ ไม่ได้จำกัดเฉพาะ GOD ตามที่เอกสารเดิมเข้าใจ ผู้ใช้ทุก role ที่ล็อกอินเข้ามาเปิดดูได้เหมือนกัน
📋 3 · Workspace · Requests (ตารางแรงงานและแผนงาน) ตารางแรงงานเทียบแผนงาน ▾

หน้า /workspace/requests — ตารางแรงงานและแผนงาน (Labor & Plans Table) สิทธิ์การเข้าถึงเหมือนหน้า Workspace ทุกประการ

  1. คลิกเมนู "Workspace" › "Requests"
  2. ดูตารางแรงงานเทียบกับแผนงานในแต่ละช่วงเวลา
  3. ปรับ/บันทึกแผนแรงงานตามสิทธิ์ของบทบาท
🏗️ 4 · Project Management (จัดการโครงการ) สร้าง/แก้ไขโครงการ ▾

หน้า /project-management — สร้างและแก้ไขโครงการ พร้อมกำหนดผู้จัดการโครงการ

4.1 ดูรายการโครงการ

  1. คลิกเมนู "จัดการโครงการ" — ระบบแสดงรายการโครงการทั้งหมด

4.2 สร้าง / แก้ไขโครงการ

  1. กดปุ่ม "สร้างโครงการใหม่"
  2. กรอก "ชื่อโครงการ", "รหัสโครงการ", เลือก "สังกัด" — ตอนสร้างใหม่ยังเลือก "สถานะ" ไม่ได้ (ระบบตั้งเป็น Active ให้อัตโนมัติ แก้ทีหลังได้ตอนกดแก้ไข)
  3. กำหนด "ผู้จัดการโครงการ (PM)" — มีฟิลด์เดียวในระบบ (ตอนเปิดแก้ไขทีหลัง ช่องเดิมนี้จะเปลี่ยนไปแสดงชื่อว่า "รักษาการผู้จัดการโครงการ (PM)" ซึ่งเป็นแค่ label สับสน ไม่ใช่ 2 ฟิลด์จริง)
  4. "ลำดับโครงการ (Auto)" — ตอนสร้างใหม่ระบบล็อกให้อัตโนมัติ กดแก้ไม่ได้ · จะแก้ได้ก็เฉพาะตอนเปิดแก้ไขโครงการทีหลังเท่านั้น
  5. กด "บันทึกข้อมูล" · แก้ไขภายหลังได้จากไอคอนแก้ไขในแต่ละแถว
ผู้ที่เข้า Project Management ได้ด้วย: FM, AM และ GOD — หมายเหตุ: เมนู "การจัดการ" ไม่แสดงตัวเลือกนี้ให้ FM เห็น ต้องเข้าผ่าน URL /project-management ตรง ๆ
