FM ทำอะไรได้บ้าง

FM (หัวหน้างาน / Foreman) เป็นบทบาทที่ทำงานหน้างานโดยตรง หน้าที่หลักคือ บันทึกรายงานประจำวัน เพื่อติดตามความคืบหน้างาน และ จัดการข้อมูลแรงงานรายวัน (DC) ในสังกัดของตนเอง

เมนูสิทธิ์รายละเอียด
Daily Reports✓ สร้าง/แก้ไขบันทึกรายงานประจำวัน ระบุแรงงาน งาน ชั่วโมง รูปภาพ
DC Management✓ เต็มสิทธิ์เพิ่ม/แก้ไข/ดูข้อมูลแรงงานรายวันในสังกัด
Overtime—ไม่มีสิทธิ์เข้าหน้านี้
Workspace—ไม่มีสิทธิ์เข้าหน้านี้

ทางลัด: Daily Reports · FM ทำเอง · การถ่ายรูป · การส่งรายงาน · DC Management

1 · Daily Reports (รายงานประจำวัน)

หน้า /daily-reports — บันทึกสิ่งที่ทำในแต่ละวัน พร้อมแรงงานที่ใช้ ชั่วโมงงาน และรูปภาพหน้างาน

1.1 เปิดหน้า Daily Reports

  1. คลิกเมนู "รายงานประจำวัน" ในแถบเมนูซ้าย
  2. ระบบจะแสดงรายการรายงานของโครงการในสังกัดคุณ สลับดูได้ระหว่างแท็บ "รอดำเนินการ (Pending)" และ "เสร็จสิ้น (Finish)"
  3. ใช้ช่อง "ค้นหา" หรือ "กรองแรงงาน" เพื่อหารายงานที่ต้องการ

1.2 สร้างรายงานประจำวัน

  1. กดปุ่ม "+ สร้างรายงาน" (มุมขวาบน)
  2. เลือก "การ์ดงาน (Task) *" ที่ต้องการรายงาน — ระบบแสดงเฉพาะ Task ที่กำหนดให้กับสังกัดคุณ
  3. เลือก "วันที่ทำงาน *" — วันที่ย้อนหลังเกิน 3 วันจะถูกล็อก ต้องขอ Unlock จาก SE/PM ก่อน
ปฏิทินจะแสดงสีวันที่มีรายงานแล้ว และวันที่ยังขาดรายงาน ช่วยให้ตรวจสอบได้ง่าย

1.3 กรอกรายละเอียดงาน

  1. กรอก "รายละเอียดงาน / งานที่ทำ *" — อธิบายว่าทำงานอะไรในวันนั้น เช่น "เทปูนคานชั้น 3 แกน A-B"
  2. ปรับ "ความคืบหน้า (%)" — เลื่อน Slider หรือพิมพ์ตัวเลข 0–100 เพื่อระบุว่างานทั้งหมดเสร็จกี่เปอร์เซ็นต์แล้ว
  3. กรอก "หมายเหตุ" (ถ้ามี) — เพิ่มข้อความเพิ่มเติม เช่น ปัญหาที่พบ วัสดุที่ขาด

1.4 เลือกแรงงาน DC และชั่วโมงทำงาน

  1. กดปุ่ม "เลือกแรงงาน DC" เพื่อเปิดหน้าต่างเลือกแรงงาน
    • ค้นหาด้วยชื่อหรือรหัสแรงงาน
    • ติ๊กเลือกแรงงานที่มาทำงานวันนั้น
    • กด "ยืนยัน"
  2. สำหรับแต่ละ Shift ที่ทำงาน ให้กรอกเวลาเข้า-ออก:
    • Shift ปกติ: เวลาเข้า / พักเที่ยง / เข้าบ่าย / เวลาออก
    • OT เช้า (ถ้ามี): เวลาเริ่ม–สิ้นสุด OT ก่อน 08:00
    • OT เที่ยง (ถ้ามี): เวลาเริ่ม–สิ้นสุด OT ช่วงพักเที่ยง
    • OT เย็น (ถ้ามี): เวลาเริ่ม–สิ้นสุด OT หลังเลิกงาน
  3. ระบุสถานะแรงงานแต่ละคน: ปกติ / ลา / ขาดงาน / Support
ถ้าไม่มี OT ไม่ต้องกรอก — ปล่อยว่างไว้ได้เลย ระบบจะคำนวณเฉพาะ Shift ที่กรอกเวลาไว้

2 · FM ทำเอง (กรณีไม่มี DC ช่วย)

ในบางวันที่ FM ลงมือทำงานเองโดยไม่มีแรงงาน DC ร่วม ให้ใช้ตัวเลือก "FM ทำเอง"

2.1 วิธีใช้

  1. ในฟอร์มสร้างรายงาน ที่ส่วน "แรงงาน" ให้ติ๊กเลือก "FM ทำเอง"
  2. เมื่อติ๊กแล้ว ปุ่ม "เลือกแรงงาน DC" จะถูกปิดอัตโนมัติ — ไม่ต้องเลือกแรงงาน
  3. กรอกรายละเอียดงาน ชั่วโมง ความคืบหน้า และหมายเหตุตามปกติ
  4. ไม่ต้องแนบรูปแรงงาน (labor photos) — ระบบจะข้ามขั้นตอนนี้ให้อัตโนมัติ
เงื่อนไข:
  • ถ้าเลือกแรงงาน DC ไปแล้ว จะติ๊ก "FM ทำเอง" ไม่ได้ — ต้องลบแรงงานออกก่อน
  • ถ้าติ๊ก "FM ทำเอง" แล้ว จะเลือกแรงงาน DC ไม่ได้ — ต้องยกเลิกติ๊กก่อน

3 · การถ่ายรูปและแนบรูปภาพ

รายงานที่ Submit จริง (ไม่ใช่ Draft) ต้องมีรูปภาพครบตามที่กำหนด

3.1 รูปภาพหน้างาน (Site Photos)

  1. ในฟอร์มรายงาน เลื่อนไปที่ส่วน "รูปภาพหน้างาน"
  2. กดปุ่มกล้อง/อัปโหลด เลือกแหล่งที่มา:
    • ถ่ายรูปใหม่ (กล้องมือถือ)
    • อัปโหลดจากคลัง (Gallery)
  3. แนบได้หลายรูป กดค้างแล้วลากเพื่อเรียงลำดับ
  4. กดไอคอน ✕ ที่รูปเพื่อลบออก

3.2 รูปภาพแรงงาน (Labor Photos) — ยกเว้นถ้าติ๊ก FM ทำเอง

  1. แนบรูปแรงงานแยกตาม Shift: Shift ปกติ, OT เช้า, OT เที่ยง, OT เย็น
  2. แต่ละ Shift ที่เปิดใช้งาน ต้องมีรูปอย่างน้อย 1 รูป ก่อน Submit จริง
  3. ถ้าไม่มี OT — ไม่ต้องแนบรูป OT
แนะนำให้ถ่ายรูปคนงานพร้อมกับบอร์ดวันที่ หรือป้ายโครงการ เพื่อป้องกันการโต้แย้งในภายหลัง

4 · การบันทึกและส่งรายงาน

4.1 บันทึกแบบ Draft (ยังไม่เสร็จ)

  1. กรอกข้อมูลบางส่วนแล้วยังไม่พร้อม Submit
  2. กดปุ่ม "บันทึก Draft" — ระบบเซฟข้อมูลไว้ก่อน ยังไม่ส่งให้ SE/PM ตรวจ
  3. รายงาน Draft จะปรากฏที่แท็บ "รอดำเนินการ" พร้อมป้าย Draft
  4. กลับมาแก้ไขและ Submit ได้ภายหลัง

4.2 Submit จริง (ส่งรายงาน)

  1. ตรวจสอบข้อมูลให้ครบ: รายละเอียดงาน · แรงงาน · เวลา · รูปภาพ
  2. กดปุ่ม "Submit" หรือ "ส่งรายงาน"
  3. ระบบตรวจสอบความครบถ้วน:
    • ต้องมีแรงงาน DC หรือ ติ๊ก "FM ทำเอง"
    • ต้องมีรูปหน้างาน (Site Photos)
    • ต้องมีรูปแรงงานแต่ละ Shift (ยกเว้น FM ทำเอง)
  4. เมื่อ Submit สำเร็จ รายงานจะย้ายไปสถานะ "รอตรวจสอบ" และ SE/PM จะได้รับการแจ้งเตือน
หลัง Submit แล้ว — FM ยังแก้ไขรายงานได้จนกว่า SE/PM จะ Approve ครับ

4.3 สรุปขั้นตอนทั้งหมด

#ขั้นตอนรายละเอียดบังคับ
1เลือก Taskการ์ดงานที่ทำ✓
2เลือกวันที่วันที่ทำงาน (ย้อนหลังได้ไม่เกิน 3 วัน)✓
3กรอกรายละเอียดงานอธิบายว่าทำอะไร✓
4ระบุความคืบหน้า (%)0–100%แนะนำ
5เลือกแรงงาน DCหรือติ๊ก FM ทำเอง✓ (เลือกอย่างใดอย่างหนึ่ง)
6กรอกเวลาทำงานเข้า/พัก/ออก สำหรับแต่ละ Shift✓
7กรอก OTเช้า/เที่ยง/เย็น (ถ้ามี)ถ้ามี OT
8แนบรูปหน้างานSite Photos✓ (ก่อน Submit)
9แนบรูปแรงงานLabor Photos แต่ละ Shiftยกเว้น FM ทำเอง
10หมายเหตุข้อความเพิ่มเติมไม่บังคับ
11Submit / Draftส่งรายงาน หรือบันทึก Draft ไว้ก่อน✓

5 · DC Management (แรงงานรายวัน)

FM มีสิทธิ์เต็มในการจัดการข้อมูลแรงงานรายวัน (DC) ในสังกัดของตนเอง ได้แก่ เพิ่มแรงงาน แก้ไขข้อมูล และดูประวัติ

วิธีใช้ DC Management แบบทีละขั้นตอนอยู่ที่ → หน้า AM › DC Management
